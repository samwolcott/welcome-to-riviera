# Riviera website

Astro static site starter using the supplied Riviera hero photograph and logo.

## Start locally

```bash
npm install
npm run dev
```

Then open the local URL Astro prints (normally `http://localhost:4321`).

## Important files

- `src/pages/index.astro` — homepage markup/content
- `src/styles/global.css` — all current styling
- `public/images/riviera-hero.jpg` — supplied hero image
- `public/images/riviera-logo.png` — supplied logo with the white background removed

## Next edits

Replace the placeholder `#` social links and `hello@example.com`, then add real music, live-date, and bio content.

## Static production build

```bash
npm run build
```

The deployable static site will be generated in `dist/`.
